# Photos

Real photography only. Drop a file here with one of these names and it appears
on the site at the next build; remove it and the section goes back to text.

| File (jpg, jpeg, png or webp) | Where it shows                       | Shape          |
| ----------------------------- | ------------------------------------ | -------------- |
| `founders.*`                  | "Who's behind this" on the home page | landscape, 3:2 |

Testimonial and case photos are set in their content files (`photo:`, `cover:`)
with a path relative to that file.

At least 2000 px on the long side. Natural light, warm tones, no stock.
